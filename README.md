# ACEW Smart Canteen

## About
ACEW Smart Canteen is a simple web application designed to make browsing canteen food items and calculating order totals easier.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Home page with a menu navigation button
- Food menu with images and prices
- Quantity selection for food items
- Add-to-cart functionality
- Automatic total calculation
- Responsive menu layout using CSS Flexbox

## How to Run
1. Download or clone this repository.
2. Keep all project files in the same folder.
3. Open `index.html` in a web browser.
4. Click **View Menu** to browse the food items.
